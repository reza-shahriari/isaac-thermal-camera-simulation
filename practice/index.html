Working practice

The conventions the code and the documents assume, one file each.

Several people and several sessions work on this repository at once, so the conventions are written down rather than carried in anyone's head: what a tolerance means, which unit a radiometric quantity is in, what a material file may author, how a step is finished. They live beside the code as skills and are published here unchanged.

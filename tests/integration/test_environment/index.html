Roadmap M2.1: the integration environment is what tests/integration and ADR 0014 assume.

tests/integration/test_environment.py on GitHub

Runs irsim_isaac.probe.probe_environment() inside the session's headless Kit and checks the facts the rest of the Isaac lane depends on. A rename in a 6.x point release fails here first, not deep inside a pipeline test. The report also lists which deprecated isaacsim.sensors.* modules Kit itself has imported (the deprecated extensions are enabled by the app profile); that irsim_isaac never imports them is an engine-free AST check in tests/unit/test_isaac_glue_imports.py.

Golden helper

Self-tests for the golden fixture helper (tests/golden/conftest.py).

tests/golden/test_golden_helper.py on GitHub

These prove the helper can tell STALE from FAILING from MISSING, refuses float16 on disk, and leaves an inspectable actual array on failure -- the properties that make golden tests a regression net rather than a liability (ir-sim-testing skill, ADR 0004).

Background golden

Golden arrays for the backgrounds a target is seen against (GT.2).

tests/golden/test_background_golden.py on GitHub

The sky and the sea are where drift is hardest to see by eye: a sky two kelvin warm still looks like a sky, and a sea profile that bends the wrong way past the horizon still looks like water. Neither had a reference array, and both feed every aerial and maritime frame this project makes.

The layered atmosphere is here for the same reason and with a worked example: AT.10 changed SWIR's transmittance by 6.5 % at 5 km while leaving the 200 m anchor exact, and not one golden moved, because all eight of them came from one LWIR config. The table below would have moved.

docs/physics-model.md §7.1, §7.4, §5.3; ADR 0004, ADR 0071, ADR 0078, ADR 0080, ADR 0113.

Isaac glue imports

Roadmap M2.1 (AST part): the Isaac glue never imports the deprecated sensor modules.

tests/unit/test_isaac_glue_imports.py on GitHub

isaacsim.sensors.camera and isaacsim.sensors.rtx are deprecated in Isaac Sim 6.x in favour of isaacsim.sensors.experimental.rtx (ADR 0014). Kit still ships and enables them, so a sys.modules check inside a running Kit says nothing about our code; this walks src/irsim_isaac with ast instead and needs no GPU.

Vehicle source solver

MP.4a / ADR 0089 — §6.6's ground-vehicle heat sources, reachable from a scene.

tests/unit/test_vehicle_source_solver.py on GitHub

The table and its integrator have existed since M6.14 and nothing outside their own unit tests could reach them. The scene schema's heat_source is ADR 0072's aerial node, whose law is a steady-state relation with no time constant at all -- so an engine bay authored through it shows its full 65 K in the first frame after ignition, which is the one thing an engine bay does not do.

test_the_rise_is_the_closed_form_and_not_a_step is the test that separates the two. Everything else guards the seams: the load profile lives on scene-relative time while the solver lives on the weather's absolute axis, and getting that offset wrong reads a plausible temperature from the wrong hour.

Housing temperature

Housing temperature source (M9.3): the three §12.2 modes feeding §8.2's self-emission term.

tests/unit/test_housing_temperature.py on GitHub

These are physics tests, not API tests. Each one is written so that it fails if the housing node stops being a first-order lag toward T_air + ΔT_self:

  • the coupled step response is checked against the closed-form exponential at τ, 2τ and 5τ, so a node that relaxed at the wrong rate, or toward the wrong asymptote, is caught at the 0.01 K level the roadmap sets — a fifth of an LWIR NETD, and 0.87 mK of apparent temperature through ADR 0016's 87 mK/K coupling;
  • the steady state is checked to be T_air + ΔT_self and not T_air, which is the mistake that makes a self-heating camera read cold;
  • ambient mode is pinned to the weather to 1e-6 K, so a node that quietly introduced a lag where none was configured is caught;
  • and a node holding a different WeatherSeries than the scene is refused at construction of the Scene (CLAUDE.md non-negotiable #6).

docs/physics-model.md §8.2, §12.2. ADR 0015, ADR 0016.

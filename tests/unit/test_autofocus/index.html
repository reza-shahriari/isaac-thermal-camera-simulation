Autofocus

OC.9 -- focus that moves (ADR 0129).

tests/unit/test_autofocus.py on GitHub

The servo is a model of passive contrast detection, not a shortcut to the right answer: it may only look at the picture. The tests hold it to the three behaviours that distinguish a real one -- it converges, it does not hunt, and it lags.

Reference statistics

ME.5: the reference report's arithmetic, on synthetic input.

tests/unit/test_reference_statistics.py on GitHub

The report generator is tested without a byte of anyone's dataset, which is the point of keeping the aggregation in irsim_eval.reference and the archive handling in the script. What is pinned here is the discipline rather than the numbers: no value reaches a report without N, a confidence interval and a floor, a value at its floor is marked as an upper bound, and anything that could not be measured appears as a refusal with a reason rather than as an absence.

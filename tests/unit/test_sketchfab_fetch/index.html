Sketchfab fetch

The licence gate fails towards quarantine, and provenance survives a round trip (AI.8).

tests/unit/test_sketchfab_fetch.py on GitHub

The gate is the one piece of this pipeline whose failure no image would ever reveal: a CC-BY-NC model committed to a public library renders identically to a CC-BY one. So these tests pin the legal semantics — exactly three licence slugs may ever be shareable, everything unknown quarantines — rather than exercising code paths. ADR 0150.

Semi transparent

Semi-transparent surfaces: the second ray and per-pixel closure (M7.15).

tests/unit/test_semi_transparent.py on GitHub

§4.4's headline capability: a windshield is opaque in LWIR and shows its own temperature, and transparent in SWIR where it shows the driver behind it. That only works if τ is carried separately from ρ -- fold it into (1 − ε) and both bands render identically, plausibly, and wrongly. These tests pin the mixing coefficients, the closure guard, and the fact that turning the feature on changes nothing for opaque scenes.

docs/physics-model.md §4.4, §4.1, §12.3; ADR 0046

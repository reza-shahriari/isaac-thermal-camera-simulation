Ros2 bridge

M10.10b: the ROS 2 message arithmetic, checked without a ROS graph.

tests/unit/test_ros2_bridge.py on GitHub

ROS 2 is a system-level install, not a pip dependency this repository can pull in, and it is not available here. So everything that can be checked without it is: the intrinsics, the encodings, the stamp, and which outputs get published at all. The part that needs rclpy is one function, and it names what is missing rather than failing with an import traceback.

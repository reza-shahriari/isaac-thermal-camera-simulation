Tick history

PT.8 — a field holds the ticks a query needs, not every tick it ever produced.

tests/unit/test_tick_history.py on GitHub

ThermalField appended every tick and pruned none, while a query only ever read the two ticks bracketing it. Measured before this step: a 24 h run of the car scenes' 10 400-cell road patch at a 30 s tick held 2 880 × 10 400 × 8 B ≈ 240 MB, and the 10⁵-cell fields the coupling lane brings would be gigabytes — which is what stopped ADR 0074's full-diurnal time-lapse.

Three claims, each of which fails if the mechanism is wrong rather than merely absent: a bounded field's memory is bounded (a leak of one tick per step fails the first test at 1 440 ticks); the state hash of a ring equals the hash a walk over the full history gives, byte for byte (a hash that forgot pruned ticks, or fed them in another order, fails); and every query inside the window is bit-identical to the unbounded field's answer (an off-by-one in the ring's index fails).

Codec floor

The floor an 8-bit, lossily-coded public set puts under every noise statistic (ME.2b, ADR 0023).

tests/unit/test_codec_floor.py on GitHub

The negative control the roadmap asks for is the first test: a cube whose true temporal sigma is 0.3 of one code must either be recovered within the stated bias or be flagged codec-limited. It is both -- Sheppard's correction lands within 0.5 % and the flag fires anyway, because at 1.04 times the floor the correction happening to work is not evidence that it can be trusted.

The codec round trips need ffmpeg and are skipped without it. They are the calibration behind ADR 0023's claim that a lossy set's noise statistic is a lower bound: the lossless case proves the harness itself is transparent, and the lossy case shows a component that was measurable before the encoder is below the floor after it.

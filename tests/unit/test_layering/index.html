Layering

Enforce non-negotiable #1: the physics core imports no engine modules -- in either direction.

tests/unit/test_layering.py on GitHub

If this fails, the physics can no longer be tested without launching a simulator, and the Unreal port stops being a glue-only rewrite. Fix the import, not the test.

Three guards:

  • nothing under src/irsim imports an engine module, the glue package, or the ML/imaging stack (that lives in src/irsim_eval, so the core stays NumPy-only);
  • nothing under tests/unit or tests/golden imports an engine module, so the default gate stays runnable without a GPU;
  • every file under src/irsim_isaac keeps its engine imports inside functions, so import irsim_isaac succeeds without Isaac Sim.

The scanner itself is self-tested on synthetic offending modules.

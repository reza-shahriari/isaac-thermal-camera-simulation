Agc vendor controls

SC.25 — the equalisation controls every thermal core has under some name (§11.3, ADR 0149).

tests/unit/test_agc_vendor_controls.py on GitHub

plateau_equalization used to have one knob, the high clip. Real cores expose a small, shared set of controls around the same histogram: the Lepton family's low clip limit (a floor of shades for every occupied bin), and the max gain that FLIR's Boson and Xenics' SWIR cores both document (a cap on how far a bland scene may be stretched). Each test below builds the scene the vendor documentation describes the control for, and asserts that the control does that job, so the test fails if the control is wired but does nothing, or does the wrong thing.

7 test(s) in tests/unit/test_agc_vendor_controls.py.

test_the_low_clip_gives_a_small_target_on_a_clear_sky_its_shades_back		A clear sky's ~30 bins hold 99.4 % of the pixels and none reaches a 7 % plateau, so plain equalisation leaves the target ≤ 3 codes. A low clip of 1e-3·N per occupied bin gives each of the target's ~120 occupied bins a floor: ≥ 20 codes, parts in temperature order.

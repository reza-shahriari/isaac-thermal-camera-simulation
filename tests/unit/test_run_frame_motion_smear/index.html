Run frame motion smear

SC.28 -- within-frame motion smear reaches `run_frame`, not only the stage beside it.

tests/unit/test_run_frame_motion_smear.py on GitHub

mtf_motion has been in the cascade since M5; ADR 0077 wired it into apply_optics and optics_stage passed the duty-scaled motion_px plane. run_frame -- what every render driver and IrCamera call -- did not, so every frame this simulator has produced was sharp whatever crossed it, while the Isaac adapter went to the trouble of synthesising the plane (IG.6). The across-frame bolometer lag was applied; the within-frame smear, the only one a cooled photon detector has, was not.

docs/physics-model.md §8.3, §9.2; ADR 0077; roadmap SC.28.

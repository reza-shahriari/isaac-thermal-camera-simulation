Material ids

Engine-free tests for instance-id → material-id transport (roadmap M10.2, ADR 0047).

tests/unit/test_material_ids.py on GitHub

The property that matters is that ids are decoded, never interpolated. A pixel on the boundary between material 0 and material 7 is one or the other; a blended 3 or 4 is a different substance with a different emissivity, and the resulting image looks entirely plausible. These tests assert that no value outside the authored set can ever appear, that a miss keeps the loud UNMAPPED sentinel instead of a convenient default, and that the magenta overlay touches display pixels only.

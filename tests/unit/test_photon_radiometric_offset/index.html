Photon radiometric offset

SC.30 -- the photon-FPA radiometric branch removes its own pedestal.

tests/unit/test_photon_radiometric_offset.py on GitHub

PhotonDetector.electrons adds the dark and cold-shield background electrons (§9.1, ADR 0066), and run_frame's inversion took the whole count as signal. Every uncooled camera in this repository was unaffected (η_cs = 1, background 0, dark small against a 300 K LWIR scene), which is why the existing photon round trip in test_run_frame.py passed: it stands an LWIR table in for MWIR. On the MWIR InSb config as shipped -- η_cs = 0.90, 2 ms integration, 8.5 Me⁻ well -- the pedestal is 3.3e5 e⁻ against 3.3e6 of signal, and a 300 K blackbody read 303.5 K.

A calibrated camera subtracts the pedestal's mean (a dark frame measures it); only its shot noise survives, which the noise budget already carries. docs/physics-model.md §9.1, §11.5; ADR 0021, ADR 0066; roadmap SC.1, SC.30.

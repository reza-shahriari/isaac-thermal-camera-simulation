Detection metrics

ME.7: the Tier 5 detection metrics, pinned on input where the answer is known by hand.

tests/unit/test_detection_metrics.py on GitHub

A detector is somebody's model; average precision at IoU 0.5 is arithmetic, and the arithmetic is what decides what a sim-to-real number means. These tests need no GPU, no torch and nobody's labels.

The metric that carries the weight for this project is P_d against SCR, not AP: a drone at 2 km subtends two pixels at an SCR of 2 and is a rounding error in an AP dominated by close, large targets -- so two sets can agree on AP and disagree completely about the regime the simulator exists to model.

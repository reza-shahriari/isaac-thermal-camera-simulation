Frame viewer

The frame viewer (irsim_viewer): a click reads the right pixel of every plane, and says so.

tests/unit/test_frame_viewer.py on GitHub

A debugging tool that shows a neighbouring pixel's temperature is worse than none, because the number looks right. So the tests pin the pixel mapping (same grid, supersampled, non-nesting), that each plane's value comes back exact and with its unit and legend name, that the server answers over real HTTP, and that the data layer is swappable -- a source that is not files at all drives the same server unchanged.

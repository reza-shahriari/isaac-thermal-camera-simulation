Validation manifest

The validation-data index (ME.1): the fields that gate a measurement, and the refusals.

tests/unit/test_validation_manifest.py on GitHub

This index is the reason a statistic from public video can be trusted at all, so the tests are about the things that would let an untrustworthy one through: a set with no recorded signal path, an analyser run on data that cannot support it, a licence silently assumed to be permissive, and a README that has drifted from the fields the code actually reads.

docs/physics-model.md §15 T4; ADR 0003.

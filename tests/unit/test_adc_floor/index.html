Adc floor

The ADC floor holds the coldest sky (docs/physics-model.md §11.1, spec issue S53, `SC.23`).

tests/unit/test_adc_floor.py on GitHub

A bolometer's DN 0 used to sit at the datasheet's −40 °C (RADIOMETRIC_RANGE_K), so every scene colder than that read one code: up to two thirds of a phantom4_perpart LWIR frame, and one enormous bin for the AGC. ADR 0151 moves DN 0 to zero scene radiance. The roadmap row asked for the band LUT's 200 K; the preset walk below is why that was not enough -- the layered model puts a clear winter zenith sky well under L_B(200 K), in every preset.

Each test fails if the floor goes back up: to −40 °C (the red reproduction and the gain ratio), to 200 K (the preset walk), or anywhere a round trip or the ceiling would notice.

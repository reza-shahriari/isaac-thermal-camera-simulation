Maritime stage

The sea ground mode, and the maritime stage's engine-free geometry (MM.5, MM.6).

tests/unit/test_maritime_stage.py on GitHub

Nothing here needs Isaac Sim: irsim_isaac.maritime_demo keeps its pxr imports inside the functions that author prims, so the placement arithmetic — which is the part that can be wrong in a way a picture would not reveal — is testable with plain pytest.

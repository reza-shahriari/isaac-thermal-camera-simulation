Warp stages contract

Roadmap M10.4, engine-free half: the Warp stage module imports without Warp, refuses what the CPU oracle refuses, and keys its device tables by content (so an identical table is never re-uploaded and a rebuilt one always is). The kernel itself is compared to the oracle in `tests/integration/test_kernels_vs_reference.py`.

Tier4 comparison

ME.6: the DN8 acceptance checks, and the control every one of them depends on.

tests/unit/test_tier4_comparison.py on GitHub

ADR 0068 replaced §15's radiometric Tier 4 targets with display-domain ones. These tests pin two things: that each statistic measures what its name says on input where the answer is known, and that synthetic versus itself passes everything -- if the control fails, the thresholds are wrong and nothing the report says about a real comparison is worth reading.

test_one_distribution_split_in_two_is_indistinguishable		The control. ⚠️ ME.6's planned criterion, "AUC 0.5 ± 0.03", is not achievable and is replaced. At this sample size the AUC's own null standard error is already 0.04, so a control that lands at 0.54 is one sigma from chance and a report calling that a failure would be measuring its own sample size. The criterion that scales with n is abs(auc - 0.5) < 2 * null_sigma.

Late defects

SC.19: defects that appear after calibration are not replaced (§10.4).

tests/unit/test_late_defects.py on GitHub

A camera interpolates over the defect map it was shipped with. A pixel that fails afterwards is not on it, so it reaches the output as an isolated stuck pixel -- the lone bright dot in a real clear-sky frame. Before SC.19 the replacement ran on the exact defect mask and no stuck pixel ever reached the image.

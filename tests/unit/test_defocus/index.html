Defocus

OC.1 -- defocus geometry (docs/physics-model.md §8.3).

tests/unit/test_defocus.py on GitHub

The oracle throughout is the thin-lens construction itself: image distances from 1/v = 1/f − 1/s and similar triangles on the exit pupil. The module ships the algebraically simplified closed form, so testing it against the construction catches a wrong simplification, which is the failure mode an "it returns a number" test would sail past.

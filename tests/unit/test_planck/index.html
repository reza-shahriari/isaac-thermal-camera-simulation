Planck

Analytic identity tests for Planck's law.

tests/unit/test_planck.py on GitHub

Every test here answers: would this fail if the physics were wrong? These catch wrong constants, dropped pi factors and unit errors -- exactly the class of bug that is invisible in the output image because AGC rescales it away.

See the ir-sim-testing skill for the tolerance conventions used.

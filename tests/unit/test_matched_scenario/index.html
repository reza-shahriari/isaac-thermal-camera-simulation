Matched scenario

M12.1: the camera and the scenarios a Tier 4 comparison is run against.

tests/unit/test_matched_scenario.py on GitHub

A comparison is only as good as the match between what was rendered and what was filmed. If the synthetic clips are clear sky at 100 m and the real ones half cloud at 200 m, the report measures the difference in scenario and the physics is never tested. These tests pin the camera against the publication's own figures, and pin the sampler's honesty about how much of the scenario is actually matched -- which on this set is none of it, for reasons ME.5 recorded.

7 test(s) in tests/unit/test_matched_scenario.py. The whole file is marked slow.

Display span

M10.23/M10.24: the manual display span, and why it has to know which band it is in.

tests/unit/test_display_span.py on GitHub

Both of §11.3's AGC modes rescale from the current frame's own histogram, so a target whose temperature is the subject looks the same in every frame -- the gain follows the target and cancels exactly the change being filmed. A real operator switches to a manual span for that, and so do these renders.

The span therefore has to be in a quantity the band actually produces. §12.1 switches apparent_temperature off for SWIR and NIR, because inverting L_B does not give a scene temperature when the signal is reflected sunlight -- so a kelvin span has no plane to apply to there, and the failure mode this module exists to prevent is rendering the other plane instead and producing a plausible picture of the wrong quantity.

Illumination bundle

M11.2 — one shading core, three incident terms, and a gate that is data rather than code.

tests/unit/test_illumination_bundle.py on GitHub

§5.2 puts the emissive/reflective choice behind a compile-time flag. ADR 0063 makes it a runtime function of band.regime, which is the only version compatible with "bands are data": a compile-time flag cannot be set by a YAML file that did not exist when the binary was built.

The tests that matter here are the ones about what the gate must not do:

  • it must not cull self-emission, or a jet exhaust goes dark in night SWIR;
  • it must not leave a trace when it drops a term, or an emissive frame with a solar plane attached is nearly the same as one without, and nobody notices the difference is real;
  • it must not let an energy-unit source into a photon-unit kernel, a mistake that is ~1e19 wide and completely invisible after AGC.

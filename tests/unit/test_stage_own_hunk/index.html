Stage own hunk

`scripts/stage_own_hunk.sh` stages only the caller's hunks — the shared-tree commit hazard.

tests/unit/test_stage_own_hunk.py on GitHub

Several sessions edit this repo's README, CHANGELOG and roadmap in one working tree at the same time, so git add README.md commits whatever another session had in flight; it has cost real prose here more than once. These tests drive the script the way two sessions actually collide: both hold an edit to one file, one commits first, and each commit must carry only its author's line while the other's stays in the worktree.

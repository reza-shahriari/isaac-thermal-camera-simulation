Render multiband

The multi-band driver's bookkeeping (M10.24).

tests/unit/test_render_multiband.py on GitHub

scripts/render_multiband.py runs three demo scenes x four bands as child processes, so almost all of it needs Isaac Sim and a GPU. Two parts do not, and both are places where a partial run silently misrepresents a complete output tree -- which is the failure mode this driver exists to prevent, since its whole purpose is that the twelve renders are compared against one another.

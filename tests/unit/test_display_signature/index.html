Display signature

What the ISP left in the picture (ME.3b, ADR 0068).

tests/unit/test_display_signature.py on GitHub

Three extractors, each checked against the thing that produced the artefact rather than against a stored number: the project's own agc_linear/agc_plateau for the histogram fingerprint, the analytic answer for a 3x3 unsharp mask for the ringing, and replace_bad_pixels for the smoothed footprint. Two of the three refuse to run on frames that are not a camera's display output, which is half of what the row is for.

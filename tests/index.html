The test suite

2,915 tests across 283 files — every one listed, with what it asserts.

Nobody has intuition for what a correct thermal image looks like — a frame that is wrong by 20 K looks exactly as convincing as one that is right. That is why this project carries 2,915 tests across 283 files, and why a test here is expected to fail if the physics were wrong rather than merely to call the function. Each file below links to its own page, where every test is listed with what it asserts.

Unit — tests/unit

Fast, engine-free, and the half of the commit gate that runs on every change. No GPU, no Isaac Sim, no network. 259 files, 2,757 tests.

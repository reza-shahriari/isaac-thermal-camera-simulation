Commands

Every script in the repository, with the first line of its own docstring.

Everything this repository can be asked to do from a shell. The render drivers need Isaac Sim and a GPU; everything else is engine-free and runs on any CPython with the dev extras installed.

commandwhat it does
audit_materials.pyAudit the thermal-material coverage of an asset from an engine-free prim dump (M7.17).
python scripts/audit_materials.py prims.json [--rules configs/materials/mapping.yaml]
                                                 [--asset phantom4]
                                                 [--threshold 0.95] [--band lwir]
build_site.pyBuild the project site — everything this repository knows, as one browsable thing.
python scripts/build_site.py                 # build into _site/
python scripts/build_site.py --serve         # build, then serve it on http://localhost:8000
python scripts/build_site.py --no-media      # skip the gallery encode (documents only, fast)
python scripts/build_site.py --out DIR       # somewhere else
python scripts/build_site.py --outputs DIR   # a different render tree ($IRSIM_OUTPUTS)
eval_detector.pyRoadmap ME.7: score a detector's output with the §15 Tier 5 metrics.
python scripts/eval_detector.py --predictions preds.json --truth truth.json
fetch_nk_tables.pyFetch the MEASURED complex-refractive-index tables from refractiveindex.info (roadmap M7.5).
python scripts/fetch_nk_tables.py --out data/nk            # every table below
python scripts/fetch_nk_tables.py --out data/nk --only glass
fetch_radcal_tables.pyFetch RadCal's tabulated narrow-band absorption data out of the FDS source (roadmap PH.5).
python scripts/fetch_radcal_tables.py --out data/spectra/radcal
fetch_validation_data.pyRoadmap ME.1: obtain, verify and hash the public validation sets (ADR 0003).
python scripts/fetch_validation_data.py --list
python scripts/fetch_validation_data.py --render-readme
python scripts/fetch_validation_data.py --plan
python scripts/fetch_validation_data.py --set halmstad_drone_detection
python scripts/fetch_validation_data.py --set anti_uav_410 --accept-unstated-licence
fidelity_ablation.pyRoadmap M12.3 (ablation half): which mechanism actually moves the picture?
python scripts/fidelity_ablation.py --clips 3 --frames 20 --out docs/validation
focus_demo.pyOC.3 -- two cubes, one in focus: the smallest thing that makes a defocused IR frame.
focus_sky_demo.pyOC.12 -- a cube against a cloudy sky, with the focus pulled from the sky onto the cube.
generate_airglow_spectrum.pyGenerate the OH-Meinel airglow spectral shape M11.4 needs (docs/decisions/0065).
python scripts/generate_airglow_spectrum.py --out data/spectra
generate_gas_luts.pyPer-band hot-gas absorption tables, generated offline (roadmap PH.5).
python scripts/generate_gas_luts.py                      # every band and every response curve
python scripts/generate_gas_luts.py --only mwir --only insb_flame_window
generate_luts.pyGenerate band radiance LUT bundles from sensor configs and spectral response data.
python scripts/generate_luts.py --configs configs/sensors --out data/lut --data data
generate_matched_scenario.pyRoadmap M12.1: render clips matched to the reference set, ready for the ME.6 comparison.
python scripts/generate_matched_scenario.py --clips 8 --frames 30 --out outputs/matched
python scripts/generate_matched_scenario.py --priors          # what is matched, and what is not
generate_nk_tables.pyGenerate the MODELLED complex-refractive-index tables (roadmap M7.5).
python scripts/generate_nk_tables.py --out data/nk
generate_response_curves.pyGenerate the modelled detector spectral-response curves (roadmap M11.1, M11.5).
python scripts/generate_response_curves.py --out data/spectra/responses
generate_solar_spectra.pyGenerate the solar spectral irradiance files M11.3 needs (docs/decisions/0064).
python scripts/generate_solar_spectra.py --out data/spectra/solar
generate_weather.pyRegenerate the committed synthetic weather sample (M6.2, ADR 0032).
python scripts/generate_weather.py [--out data/weather/clear_midlat_summer_48h.csv]
next_step.pyWhat to do next, computed from docs/roadmap.md rather than written into it.
python scripts/next_step.py              # the one step to start now
python scripts/next_step.py --queue 20   # the next 20, in order
python scripts/next_step.py --lane PT    # restrict to one lane
python scripts/next_step.py --write      # publish the queue into docs/roadmap.md
python scripts/next_step.py --check      # fail if what is published has drifted
python scripts/next_step.py --json       # the whole order, for tooling
parked_car_cabin.pyThe cabin reference scene, engine-free: a parked car and the air behind its panels (PT.15).
prep_asset.pyPrepare a third-party 3D asset for the simulator: rescale, convert to USD, audit its materials.
python scripts/prep_asset.py --asset phantom4
python scripts/prep_asset.py --asset phantom4 --source 3d_models/phantom4.fbx         --out-dir data/assets
probe_isaac_asset.pyProbe: does a prepared third-party asset load in Isaac Sim, and does its mapping resolve there?
probe_isaac_camera.pyRoadmap M10.9a: record which lens-distortion schemas this build carries, and their defaults.
probe_isaac_environment.pyRoadmap M2.1 + M2.2 gate spike: boot Isaac Sim headless, record the environment, author the temperature-ramp scene, read back every candidate AOV in the real-time and path-traced modes.
probe_isaac_geometry.pyRoadmap M10.1: survey the geometry AOVs on the lit, tilted, moving probe scene.
probe_isaac_spg.pyRoadmap M2.3: SPG capability experiments (float32 pass-through, persistent state, LUT delivery).
probe_warp_mesh.pyRoadmap WM.1: can Warp recover exact per-pixel (face, u, v) on this build?
probe_warp_prim.pyRoadmap WM.1, the in-Kit half: a wp.Mesh built from a prim's own points and indices.
quad_flight_mesh.pyThe quadrotor's arms as tubes, engine-free (WM.7).
quad_flight_pointwise.pyThe aerial scenario, regenerated point-wise and engine-free (PT.9).
radcal.pyRadCal's CO2 and H2O narrow-band absorption coefficients, ported to NumPy (roadmap PH.5).
reference_statistics.pyRoadmap ME.5: measure the public reference sets and write the bands the simulator must land in.
python scripts/reference_statistics.py --list
python scripts/reference_statistics.py --set halmstad_drone_detection
python scripts/reference_statistics.py --set halmstad_drone_detection --limit 20
render_aerial_demo.pyRoadmap M10.19: render the phase-1 aerial demo stage through IrCamera and export the frames.
render_aircraft_pass.pyRoadmap M10.21: film a light jet flying a low pass, in LWIR (ADR 0075).
render_car_ignition.pyRoadmap MP.4b: film a cold car starting its engine, in LWIR, with a per-pixel temperature field.
render_maritime_demo.pyRoadmap MM.7: render the maritime demo stage — vessels on open water — and export the frames.
render_multiband.pyRender each demo scene in all four bands, with a registered visible companion.
render_phantom4.pyRoadmap AI.2 (in-engine half): fly an imported third-party aircraft, in LWIR and in colour.
render_quad_flight.pyRoadmap M10.20: film a heavy-lift quadrotor flying a mission, in LWIR (ADR 0074).
render_quad_outbound.pyRoadmap PT.9 / IG.2: film a quadrotor going away from the camera, point-wise (ADR 0123).
render_vessel_departure.pyRoadmap MM.7: film a vessel getting under way and steaming out to the horizon, in LWIR.
site_gallery.pyThe demo gallery: the frames and clips the simulator has actually produced, made web-sized.
site_layout.pyThe shell every page of the project site is poured into: nav, table of contents, styling.
site_markdown.pyMarkdown to HTML, with no dependency outside the standard library.
site_survey.pyThe pages of the site that are measured from the repository rather than written by hand.
train_detector.pyRoadmap ME.7: train a small detector under one of §15's four transfer protocols.
python scripts/train_detector.py --protocol real_to_real --real <dir> --out runs/r2r
python scripts/train_detector.py --protocol synthetic_to_real --real <dir> --synthetic <dir>
validate_atmosphere_band_average.pyQuantify the grey-band (single gamma_B) atmosphere approximation error (ADR 0048, M8.7).
python scripts/validate_atmosphere_band_average.py
validate_sky_r13.pySky apparent temperature vs elevation from the layered atmosphere against the R13 anchors.
python scripts/validate_sky_r13.py
validate_thermal_diurnal.pyPlot the M6.13 facet scene's 24 h diurnal curves, for the manual half of the Tier 3 pass.
python scripts/validate_thermal_diurnal.py --out outputs/thermal_diurnal.png
validation_report.pyRoadmap ME.6: the Tier 4 acceptance report. Exits non-zero when a target is exceeded.
python scripts/validation_report.py --real <dir> --synthetic <dir>
python scripts/validation_report.py --self-test
wall_half_in_sun.pyThe R1 reference scene, engine-free: one building's faces at their own temperatures (PT.20).
